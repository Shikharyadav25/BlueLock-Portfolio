# Blue Lock Portfolio

A Blue Lock-inspired portfolio website built using React.

## Technical Details
- **Component Architecture & Routing:** Built with React 19 and React Router DOM for modular page views (`/`, `/about`, `/socials`, `/projects`) with persistent audio playback across routes.
- **State & Keyboard Navigation:** React hooks (`useState`, `useEffect`) manage item selection, audio state toggles, and keyboard shortcuts (`ArrowUp`, `ArrowDown`, `Enter`, `Escape`).
- **Styling & UI Elements:** Scoped Vanilla CSS with CSS variables, geometric transforms (`skewX`, `skewY`), high-contrast drop shadows, and `clip-path` polygon cuts for diagonal buttons, telemetry cards, and status badges.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```
   The app will run locally at `http://localhost:3001/`.

3. **Build for production:**
   ```bash
   npm run build
   ```
